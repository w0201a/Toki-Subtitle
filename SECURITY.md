# Source publication checks

Only application source, required resources, tests, Gradle configuration and public project documentation are tracked. Local signing files, credentials, build outputs, APKs, device diagnostics, screenshots and host analysis artifacts are excluded.

The local `docs/` directory is ignored by default. Only the curated public `ISSUES_AND_FIXES.md` and `LINKS.md` are explicitly allowed, so routine staging does not include private troubleshooting records.

Before publishing, scan the staged content with Gitleaks:

```sh
gitleaks protect --staged --redact --config .gitleaks.toml
```

The narrow allowlists cover `cache.key=<64 hex characters>` lines in bundled host profiles and exactly eight SHA-256 structural-hash entries for four named public Aweme fields in `toki-extension-profile.properties`. The latter describe field type, annotations and usage, not field contents. These are public SHA-256 fingerprints generated by `HostScanPlan` using `HostDexIndex.digest`, not API or authentication keys. Other secret detection rules remain enabled.

The subtitle translation path uses the host application's native translation service and does not require a user-provided third-party translation API key. The two sponsor payment QR images are intentionally public resources supplied for this edition.
