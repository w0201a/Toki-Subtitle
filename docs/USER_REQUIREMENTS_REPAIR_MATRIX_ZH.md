## 一、需纠正或特别强调的历史理解

1. **“更多离线缓存格式导出”已被用户纠正为“离线视频导出”**：把TikTok已有的完整离线视频保存到相册／文件，不是追求更多缓存后缀。分轨合并和封装仅为实际导出所需，不能改后缀冒充转换。
2. **HDR真实意图是关闭HDR、按SDR播放，不是强制启用HDR**。后来用户已停止这项，不能把屏幕支持HDR或曾输出HLG当成关闭HDR验收，也不能自动重新开始。
3. **图片帖黑屏曾被指定优先级100，但2.0.88已获用户确认图片与左右轮播恢复**。原因是指示器净化误隐藏轮播行为根；不是图片源缺失，不应再让用户重下图片或全关净化。
4. **离线联网政策已被用户修改**：有网时允许在线翻译与补数据，断网依靠持久本地缓存／可用本地引擎。不能继续引用最初严格禁止联网的版本来否定后台准备；只读离线预览／保存缺缓存时仍应提示，不暗中转为下载。
5. **字幕问题不只翻译速度**：用户报告过译文到达不及时、循环播放后错句、间歇消失、原生与自定义样式均可能卡住，电影最明显但不限于电影。须按各自条件判断，不能用一个翻译请求成功替代播放时序验收。
6. **“丢弃过期结果”只丢失效异步回调的界面应用资格**：换视频／账号／页面／字幕轨道后，旧任务不能写到新页面；不等于删除已下载视频、历史评论、译文或本地档案。
7. **“所有设置实时生效”与“更换模块代码必须重新加载”不是一回事**：已支持的运行时设置要热应用、关闭可恢复；安装新模块或用户主动重新扫描所需的完整宿主重启，不能伪装成开关热生效。
8. **独立Toki与宿主Toki同步要覆盖Root和免Root**，不能只证明外部写入宿主，用户还明确要求宿主内修改自动回写外部本体。一次字号24→25→24的成功只证明该条路径，不证明全部配置一致。
9. **截图圈定组件要独立可选隐藏**：不能以隐藏整个播放器、图片轮播、共享父容器、全部分享项替代精准净化。图片可见性与原生手势是必须守住的回归边界。

## 三、早期截图和优先级的正确用法

早期优先级5：贴图下载入口、离线长按、他人主页视频国家。优先级4：国家／地区／运营商／位置、分享项、HDR。优先级3：直播上下滑。随后图片黑屏升到100；再后图片恢复、部分功能获得接受、HDR停止、离线评论出现新故障。**这些数字是历史记录，不是现在立即重新执行的排序。**

原截图语义不能丢失：
- 快速评论：个人主页的视频也会出现，不能只看推荐页。
- 模板：特效／模板业务入口，不是隐藏整个内容区域。
- 分享：各外部渠道与“创建群组／设置壁纸／GIF分享”可逐项选，不只是侧边分享箭头。
- 搜索：底部推荐、视频详情顶部搜索条、搜索页推荐／热榜／历史是不同组件。
- 作者区：“转发给粉丝”与国家／作者名显示不是同一功能。
- 图片帖：下载缩略图正常是显示层故障线索，不是要求重新下载的理由。

原始截图、设备导出ZIP、日志、配置和宿主反编译资源只留本地，不随本表公开提交；本表仅概括需求和已有证据。
