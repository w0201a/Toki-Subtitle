## 直播上下滑动限制

原适配符号在当前已检查宿主中命中触摸监听器。只截断监听器回调不足以阻止实际翻页容器。本轮从该监听器所属直播Fragment的已核对字段解析实际ViewGroup，同时校验并绑定其原生拦截、触摸入口和所属监听器。

超过纵向滑动阈值后，整段手势保持锁定至抬手／取消；同时取消原生拖动状态，避免拖回或后续抬手重新触发翻页。处理活动手指切换；已锁定时关闭开关会消费完当前手势，下一手势恢复。点击、横向手势和程序化切页保留原生处理。不会全局拦截其他ViewGroup。
