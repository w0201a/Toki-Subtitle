# 问题、修复与验证记录

维护范围：Toki 字幕版。原作者为 [MeiYongAI](https://github.com/MeiYongAI/Toki)，字幕版由 **154Er · Gi-Ai154M** 维护。

本页是经过整理的公开问题记录，不上传原始设备日志、视频正文、用户截图、API 凭据或宿主反编译内容。版本改动见 [CHANGELOG](../CHANGELOG.md)。

## 已确认修复

| 问题 | 原因与处理 | 验证与边界 |
| --- | --- | --- |
| TikTok 清屏后字幕消失 | 原字幕父容器被隐藏；2.0.3 将实际字幕帧交给可见视频页上的独立绘制层 | 用户确认修复；切流及离页仍隐藏旧字幕 |
| 翻译比之前更慢 | 当前句与预读互相取消，同句复用和排队去重不足；2.0.4 调整调度 | 用户后续反馈正常；未建立同视频固定性能基准 |
| 评论投票不翻译 | 最初使用的投票绑定名称与真实 DEX 签名不符；2.0.7 修正绑定契约 | 题目和选项请求成功，用户确认正常 |
| 长标题／正文请求成功却仍显示原文 | 原生数据更新后最终布局仍使用旧原文；2.0.8–2.0.11 中间方案未完成显示修复，2.0.12 重构最终布局入口 | 实机展开画面确认多段中文已显示；语义未逐句核验 |
| 赞助码造成 Release 资源编译失败 | 输入文件实际为 JPEG，扩展名却为 PNG；2.0.15 改用真实 JPEG 扩展名与导出 MIME | Release 构建通过，包内图片字节与原图一致 |
| 新增署名／赞助文案影响资源测试与 lint | 新增文案混入上游固定目录，且语言回退和读取原图的类型标记缺失 | 独立文案文件、明确英文回退、局部资源类型注解；最终 GitHub 检查通过 |

## 仍需注意与待回归

| 项目 | 当前状态 | 复现／反馈建议 |
| --- | --- | --- |
| 中文回退正文中的话题、链接点击 | 最终布局补偿使用纯文本；原生展开／收起和原文入口可见，富文本交互需继续实机回归 | 提供字幕版、TikTok 版本及点击对象类型，无需贴私人正文 |
| 后两条视频预读 | 已实现按推荐列表顺序、有限缓存和低优先级调度；命中取决于宿主是否提供可用字幕地址 | 区分当前句响应和下一条首句响应；无字幕视频不作为预读成功保证 |
| 无原生字幕的视频 | 当前依赖可读取的原生字幕和宿主翻译；不等同于通用 OCR／语音识别 | 反馈时说明原视频是否提供字幕轨 |
| TikTok 版本差异 | 当前字幕版主要在 47.0.3 实机验证；内部类与方法会随版本变化 | 提供宿主版本及下载渠道，不上传宿主 APK／反编译文件 |
| 新增文案的其他语言 | 字幕版新增文案支持英文、简体中文，其他语言使用英文回退；上游语言目录保留 | 可通过 Pull Request 补充翻译 |
| Debug 与 Release 互相覆盖 | 使用不同证书，Android 阻止直接覆盖；不是签名校验失败 | 自行迁移前备份配置；维护脚本不卸载或清空应用 |

## 后续维护方式
